# View a recorded Ag synthesis example

This optional example displays a previously generated Ag synthesis route, its recorded evaluations, and the associated laboratory outcome. It uses saved study data and requires no API key; it does not generate or evaluate new routes.

## Run the example

With Python 3.12 installed, open a terminal in the repository root (the directory containing the main README) and run:

```sh
python3.12 scripts/recorded_example.py
```

The [script](../scripts/recorded_example.py) uses only the Python standard library. No package installation or model calls are needed. For a new generation and evaluation run, follow [Installation and usage](../README.md#installation-and-usage).

## What it shows

The example follows Claude Opus 4.5's polyol route for Ag nanowires, `1561.json_Ag_1749/route_3.json` (expert route ID 4). The script reads the saved protocol and its three retrieved literature procedures, gathers the recorded scores, and adds the laboratory outcome from the study's experimental records.

The terminal displays the saved mean CPC, Answer Relevancy, and original Faithfulness scores, followed by three separate SS-Faithfulness evaluations by Llama 4 Maverick. Original Faithfulness and SS-Faithfulness are reported separately because they use different evaluation criteria. It also summarizes the recorded laboratory outcome.

Three files are saved in `outputs/recorded_example/`:

| File | Contents |
|---|---|
| `route_3.json` | The protocol previously generated by Claude Opus 4.5. |
| `retrieval_context.json` | The literature procedures supplied during generation. |
| `summary.json` | The recorded scores, repeated SS-Faithfulness evaluations, laboratory outcome, and links between the source records. |

Repeated runs reuse matching files and recreate missing files. Edited outputs are never overwritten. To save a separate copy, choose another directory:

```sh
python3.12 scripts/recorded_example.py --out outputs/recorded_example_2
```

## Study records

The files used by the example are included in the repository:

| Record | Source |
|---|---|
| Generated protocol | [Ag route](../synthway/generation_routes/output_LLM_stratified_anthropic_claude-opus-4.5/1561.json_Ag_1749/route_3.json) |
| Retrieved procedures | [Retrieval context](../synthway/generation_routes/output_LLM_stratified_anthropic_claude-opus-4.5/1561.json_Ag_1749/retrieval_context.json) |
| Saved mean scores | [Route scores](../synthway/bench/all_models_merged_metrics_selected_40_median3.csv) |
| Repeated Llama evaluations | [Claude–Llama evaluation records](../paper_tables/examples/Claude_Llama_evaluations.json) |
| Laboratory protocol and outcome | [Table S20](../results/source_data/table_s20.csv) and [experimental outcomes](../results/source_data/figure_4_outcomes.csv) |

The Claude–Llama JSON contains evaluations of ten routes in three repeats for each of Table 1 (SS-Faithfulness), S18 (CPC), and S19 (Answer Relevancy and original Faithfulness), as well as saved generation statistics and three regeneration repeats. The viewing script selects the Ag route's Table 1 evaluations from this collection; regeneration records remain available for inspection in the JSON.

The Ag laboratory example is reported in Table S20 and Figures 4/S4. Regeneration results are summarized in Figures 5/S6. These table and figure numbers refer to the manuscript.
